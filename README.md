# TutorConnect
Plataforma web de tutorías y asesorías académicas del TecNM Campus Pachuca

## Objetivo general
Desarrollar una plataforma web que centralice la solicitud, la disponibilidad, la programación y el seguimiento de las asesorías académicas, para vincular de forma eficiente a los estudiantes del TecNM Campus Pachuca con profesores y alumnos asesores, facilitando el acceso al apoyo académico y fortaleciendo el acompañamiento estudiantil.

## Tecnologías contempladas
* **Frontend:** HTML5, CSS3 y JavaScript ES6+ (arquitectura de páginas web sin compiladores ni servidor propio).
* **Estilos y conexión cliente:** Tailwind CSS (vía CDN) y `supabase-js` v2 (cargada mediante etiqueta `<script>`).
* **Backend y base de datos:** Supabase (PostgreSQL con vistas, funciones RPC y políticas RLS) y Supabase Auth (registro, inicio de sesión y contraseñas cifradas).
* **Entorno de desarrollo y control de versiones:** Visual Studio Code con extensión Live Server, Git y GitHub (con GitHub Desktop)[cite: 7].
* **Despliegue:** GitHub Pages (publicación web directa)[cite: 7].
